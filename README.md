# MensLink

为人和 Agent 提供有来源、版本和定位的本地知识，配合 Obsidian 与 Codex 使用。

**开发中，暂无可下载产品或正式版本。** 当前仓库已建立工程治理基线；产品源码与技术验证通过后续 PR 接入。不要将仓库创建或 CI 通过视为产品交付。

开发采用 `main → codex/<topic> → PR → CI → main`，先验证关键技术，再提供最小原型供评审。见 [开发流程](docs/development.md) 与 [参与开发](CONTRIBUTING.md)。

问题请用 [Issues](https://github.com/ga626/MensLink/issues)，安全问题请用 [私密漏洞报告](https://github.com/ga626/MensLink/security/advisories/new)。请勿上传私人资料或凭据。

自有代码采用 [MIT](LICENSE)，第三方依赖仍适用各自许可。
