# ADR 0001：按个人开发条件推进第一阶段

状态：接受用于本次搭建。依据：2026-10-20 用户补充指令。

目标是尽快形成可运行、可判断的工程基线。旧计划把虚拟机、多平台和双引擎对照集中在 P1，用户明确当前只有个人电脑，允许本机技术验证和自主阶段划分。

比较两种可实施方式：A 在本机准备小范围样本库，搭建核心、CLI、读取桥并做风险定向检查；B 先备齐双系统 VM 和完整候选矩阵再开始源码。A 调用链短、失败容易定位、可直接删除测试库；B 更接近发行环境但阻塞当前开发，且不具备设备条件。

选择 A。项目 `local/` 保存测试数据和工具链，检查用公开合成样本；不迁移或接入个人库。无需为开发强制 worktree、容器、虚拟机或新 MCP 注册。现有运行时能支持的验证直接进行，网络下载只改变项目目录。

保留 Win10/Win11 产品目标。Win11、干净安装、最低宿主等在实际发布前补；设备暂缺就标未验，不能冒充通过。本阶段源码、开发构建、产品候选与公开版本继续分开。

回退：停止本项目读服务，保留源码和报告；测试库、SDK、缓存均在项目内，清理前核对具体目录。不会反向修改个人库、账号或宿主配置。
