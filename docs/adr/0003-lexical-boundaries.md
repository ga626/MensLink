# ADR 0003：跨块字面检索与旧引用兼容

状态：本机合成检查通过，采用为开发基线；不是总体中文检索质量或性能结论。

固定 1200 code point 无重叠分块，会使边界上的短语分散到两个片段。固定小型中英语料的首次 15 项检查有 3 项漏召回，包括增补 Unicode 字符与长查询。失败回执保留，不以新结果覆盖。

| 方案 | 调用、迁移及代价 |
|---|---|
| A：段落/换行优先并有限重叠 | Core 内部调整，默认上限 1200 code points，重叠为最大查询长度减一，即 499；现有 SQLite 查询不变。新增片段增加存储，但可覆盖支持范围内的跨界字面查询 |
| B：搜索整份正文并动态构造命中 | 需要改查询、片段身份和固定引用生成，长文扫描与短词成本上升；引入第二套定位及预算逻辑 |

采用 A。查询上限统一由 `Wire.MaxQueryCodePoints=500` 声明。在片段后半段优先寻找段落边界，再找换行；没有边界才硬切。重叠保证所支持的连续字面查询完整落入某个片段，不承诺繁简转换、别名或语义召回。

旧库不静默重建。用户再次确认导入相同资料时，在同一事务中只补缺少的范围；已有来源、修订、片段及引用不删除，若增加片段则提高索引代际。重复导入不再增加代际；撤销或授权冲突仍先拒绝。代价是旧库可能保留部分重叠命中，之后可在不破坏固定引用的前提下优化排序与去重。

默认 JSON 转义会使长中文片段超过默认响应预算。采用允许 Unicode 的安全 JSON encoder，继续按实际完整序列化结果核预算，保留 HTML 敏感字符转义；不把 JSON 直接作为 HTML 插入。出处与完整片段仍不得被静默截掉。

定向验收：核心 26/26、固定真值 15/15、官方 MCP SDK 探针 8/8。覆盖最大 500 字符与 501 拒绝、默认中文预算、增补字符/行号、旧库补索引、旧引用不变、幂等及撤销。没有改协议字段或数据库表结构；没有接私人库、模型或新依赖。
