# 产品范围

MensLink 为人和 Agent 提供可追溯的本地知识。Obsidian 是主界面，Codex 是首个 Agent 接入方；不捆绑宿主、不依赖 KnowledgeRadar。本文件是既有 v0.3 产品计划的公开范围摘要，阶段调整不取消下列目标。

- 来源、不可变修订、原件与内部文字分离，引用有出处、版本和定位。Agent 返回候选证据，不把索引命中当作真实性或完整性保证。
- 本地资料默认 `local_only`，明确授权后才交给 Agent；撤销应作用于检索、旧引用、缓存与在途结果。MCP 只读，资料内容不是操作授权。
- Obsidian 管理 MD/TXT、数字 PDF 与网页资料；人改内容独立保存，重跑不能覆盖人工编辑。导入先预览并确认，任务可取消、恢复与幂等执行。
- 自动同步仍属正式首发目标，须有真实账号/权限、增量与失效处理；至少一条真实同步闭环及小红书专项结论。手动粘贴与模拟不能替代此目标。
- 经验形成需人工批准，规则不加权、不自动写用户规则；不扩大为独立聊天产品。
- Windows 10 22H2 x64 与 Windows 11 x64 为目标；程序、用户数据与 Vault 分离，安装、升级、回退和卸载保数据须分别验证。
- 检索先建立可验证词法基线，只有质量反例与具体收益才引入语义引擎或模型。PDF、网页、平台、外部引擎需记录覆盖与失败，不把计划字段当已实现。

当前实现与参数见 [实现合同](reference/implemented-contract.md)，实际验证及缺口见 [当前状态](../project_status/current.md)，下一步见 [技术验证与原型计划](plans/validation-prototype-github.md)。最小原型先使用合成 Vault 的 MD/TXT，用户看过效果后再扩展；正式发布门仍包括同步、格式覆盖、兼容及同制品交付。
