# 当前开发版本的隐私边界

本阶段使用项目合成样本。程序只读取显式预览的单个 MD/TXT 文件；原件不移动或改写。不会扫描全盘、连接平台账号或自动修改 Obsidian/Codex 配置。

CLI 导入默认 `local_only`。加上 `--allow-agent` 才允许来源通过本产品 MCP 只读接口返回；这是对该来源的显式选择。远端 Agent 收到片段后，内容可能进入其提供方的数据处理范围，本产品不能撤回已返回的文字。

本地 CLI 是当前用户的管理/阅读入口，可见其指定库内资料；MCP 进程只连接同用户的指定库读管道，过滤未获准来源。此界限不防御已控制同一用户账号的其他程序。

文字快照和修订保存在指定实验数据目录的 SQLite 中。撤销停止后续检索，不自动擦除数据库历史，不删除源文件；物理清理、备份和保留策略属于后续完整产品能力。当前不要把长期私人知识库导入实验 schema。

普通文字处理、检索及只读服务不调用模型或下载内容。开发安装 SDK/NuGet 会访问官方分发端点，与资料处理分开。诊断/检查回执留本地，当前没有自动上传或遥测实现。
