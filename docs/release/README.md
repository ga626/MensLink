# 公开开发与发布准备

公开仓库`ga626/MensLink`已按确认的公开/main/MIT策略建立，支持用Issues，漏洞走GitHub私密报告。仓库基线与源码PR不等于可下载或已交付产品；当前没有正式版本、安装包或稳定入口。

标准链路为Bootstrap远端基线→治理PR（最小权限CI、真实入口与成功检查后的保护）→产品PR→原型评审→发布准备。签名主体、原生host与Obsidian社区渠道在实际交付时核实，不借用占位信息。

公开前核tracked/untracked、历史、秘密、个人路径、许可与包排除。原调研资料留维护者本地，公开实现文档不链接缺失的私有回执。第三方运行时和原生依赖须核LICENSE/NOTICE、漏洞与SBOM，自有MIT不替代其义务。

产品候选须从干净、确切源码构建并绑定摘要及场景，普通开发输出不安装到稳定路径。正式发布采用同一已验制品贯穿真实环境、tag/Release与下载核摘要；签名改变字节也需重新核身份。没有正式交付需求的治理或开发源码PR不机械发版。

Windows10/11、Obsidian真实加载、Codex Desktop/CLI、安装升级/回退/卸载保数据、账号首用和用户体验分别记录。模拟、SDK探针、CI和开发样机不能代替这些结果。
